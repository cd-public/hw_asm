Load and Store Instructions RISC-V is a “Load/Store architecture”. That means that only a specific class of instructions are used to reference data in memory. As a rule, data is loaded into registers first, then processed, and the results are written back using stores. Store Word (sw) ■ Used to store 4 bytes (one word) of data to memory ■ sw rs2 offset(rs1) – rs1 is a register that holds a memory address – offset is a signed 12-bit immediate value – rs2 is the value that will be written at this address M[R[rs1] + offset] = R[rs2] 10

Two Stage Pipeline 1. What is the longest combinational path? – Multiplier – 1200ps 2. What is the min clock period? • Clock-to-q delay + longest combinational delay • 20ps + 1200ps = 1220ps 3. If the clock period is at least the min period, how many clock cycles does it take to perform one operation? – two 4. If we run this circuit at the minimum clock period, how long will it take to complete 10 operations? – Final result is available at t = (1220ps)(10+1) = 13420ps 50

Three Stage Pipeline 1. What is the longest combinational path? – Multiplier – 1200ps 2. What is the min clock period? • Clock-to-q delay + longest combinational delay • 20ps + 1200ps = 1220ps 3.
