Digital Logic

  • Logic circuits are used to build computer hardware, as well as many other types of systems (microwave, car).
    • All such systems are broadly classified as digital hardware.
  • Digital derives from how information is represented as discrete ranges of electrical signals.
    • Using discrete ranges provides robustness and scalability.

Its “New”

  • Digital hardware technology has evolved dramatically over the past 75 years!
    • As old as e.g. Brown v. Board
  • In the 1960s logic was built with discrete components, transistors and resistors.
  • Integrated circuits (ICs) made it possible to place a number of transistors on a single chip.

Working Definition

A Computer Engineer’s Definition

Information resolves uncertainty.

  • Information is simply that “stuff” which cannot be predicted.
  • The less likely a message is, the more information it conveys.

Quantifying Information

  • Suppose you’re faced with \(N\) equally probable choices,
    • E.g. Diet Coke, Coke Zero, Cherry Coke, Vanilla Coke
  • And I give you a fact that narrows it down to M possibilities.
    • It’s flavored, so Cherry or Vanilla
  • This is worth \(\log_2(\frac{M}{N})\) information.
    • The unit for information is bits

Examples

  • Outcome of a coin flip: \(\log_2(2/1)\) = 1
  • Roll of one die: \(\log_2(6/1)\) ≅ 2.6
  • Roll of one die is odd: \(\log_2(6/3)\) ≅ 1

Exercise

  • A 7-digit phone number is a palindrome.
  • Proceed manually.
    • Get an approximate solution absent any tools, or
    • Express the solution in \(\LaTeX\), or
    • Express the solution in a python script.

Solution

  • Each (decimal) digit stores \(\log_2(10)\)
  • 7 independent digits stores up to \(\log_2(10^7)\)
  • A palindrome causes the final 3 to be determined by the first 3.
  • 4 independent digits stores up to \(\log_2(10^4)\)
  • Discloses \(\log_2(10^7/10^4) = \log_2(10^3)\)
    • \(10^3\) ≅ \(2^10\) so approx. 10 bits.

What do programs really do?

Quoth Kaki:

At this point in your CS career, you look at a program specification and figure out what it does!

int f(int x) {
    int r = 0;
    while (++r * r <= x) {}
    return r - 1;
}

How does a computer do it?

cat f.c
int f(int x) {
    int r = 0;
    while (++r * r <= x) {}
    return r - 1;
}
gcc f.c -S && cat f.s
f:
.LFB0:
    endbr64
    pushq   %rbp
    movq    %rsp, %rbp
    movl    %edi, -20(%rbp)
    movl    $0, -4(%rbp)
    nop
.L2:
    addl    $1, -4(%rbp)
    movl    -4(%rbp), %eax
    imull   %eax, %eax
    cmpl    %eax, -20(%rbp)
    jge .L2
    movl    -4(%rbp), %eax
    subl    $1, %eax
    popq    %rbp
    ret

What do we see?

  • Four operations, one each of:
    • \(+\), \(\times\), \(-\), \(\geq\)
  • Many moves
    • Including push, pop
  • Some control
    • “Jump”, return, “nop”

271 Review ☺

Base

  • A base is the number of different digits that a system can use to represent numbers
  • Binary is base 2 because it has the digits 0 and 1
  • Decimal base 10 because it has the digits 0-9
  • Hex is base 16 because it has the digits 0-F

Binary Notation

  • Always prepend binary numbers with “0b” or add a subscript of 2
    • Ex: 0b1001 or \(1001_2\)
  • Place binary numbers in groups of four to make it easier to read
    • Ex: 0b 1010 1111 0101 or 0b1010_1111_0101
    • If you cannot evenly break up the number into groups of four, start making the groups from the right
      • Ex: 0b10_1010_0011

Hex Notation

  • Always prepend hex numbers with “0x” or add a subscript of 16
    • Ex: 0xE2A or \(E2A_{16}\)

Decimal Notation

  • You can indicate that a number is a decimal value by adding a subscript of 10
    • Ex: \(54_{10}\)
    • I will sometimes use 0d54
  • If a number does not have a leading “0b” or “0x” and does not have a subscript, it is assumed to be a decimal value

Overflow

  • Adding two values of \(n\) digits requires \(n+1\) digits to store the sum.
  • Multiply two values of \(n\) digits requires \(2n\) digits to store the product.

Carry/Overflow

  • Doesn’t always happen
1 0 1 0
+ 0 1 0 1
= 1 1 1 1

Carry/Overflow

  • When it happens it matters
0 1 0 1
+ 0 1 0 1
c 1 1
= 1 0 1 0

Carry/Overflow

  • Carries can overflow
1 1 1 1
+ 0 0 0 1
c 1 1 1 1
= 1 0 0 0 0

Two’s Complement

  • Suppose we want to model negative numbers in hardware.
    • I have no idea why we would do that.
    • Ask people that use computers, not make them.
  • Consider the following.
    • -1 is the value to which we add 1 to get zero
    • To what binary value does adding 1 yield zero.

Two’s Complement

  • Fix \(n\) bits of precision.
  • Add 1 to “\(n\) 1s” to get zero.
1 1 1 1
+ 0 0 0 1
c 1 1 1
= 0 0 0 0
  • Use the most significant/first bit as a sign bit.
