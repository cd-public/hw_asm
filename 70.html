Take Away: How to determine the minimum clock period? min clock period = clk-to-q delay of the input registers + adder propagation delay 9

In General… min clock period = clk-to-q delay of the input registers + longest combinational path 10

Min Clock Period ■ Why do we not include the clk-to-q delay of the output register when determining the min clock period? 11

Min Clock Period ■ Why do we not include the clk-to-q delay of the output register when determining the min clock period? In one clock cycle, we need to read the input registers, compute their sum, and ensure the value is ready for the output register before the next rising edge of the clock. The value will not pass through the output register until the next rising edge of the clock. 12

■ Why do we not include the clk-to-q delay of the output register when determining the min
clock period?
In one clock cycle, we need to read the input registers, compute their sum, and ensure the value is ready for
the output register before the next rising edge of the clock. The value will not pass through the output register
until the next rising edge of the clock.
