## Don’t Care Outputs

■ When designing our circuits, we will treat X as a 0 or a 1
depending on which decision yields the fewest number of
transistors.
■ How do we know which decision is better?
– In a K-map, if treating the X as a 1 yields fewer or larger
circles, then treat it as a 1.
– If not, treat the X as a 0.
– If there are multiple X’s in a truth table, handle them
individually
■ i.e. you can treat some X’s as 1s and some X’s as 0s
